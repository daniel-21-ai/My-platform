# My-platform

## Счётчик КБЖУ (`index.html`)

Одностраничный счётчик калорий, белков, углеводов и жиров. Открыть `index.html` в браузере — сервер не нужен.

- Задаёшь дневные цели в 4 ячейках (1 – 1 000 000).
- В каждой ячейке вычитаешь съеденное (Enter или «−») или прибавляешь («+», либо число с плюсом: `+120`).
- Видна история всех действий за день, последнее можно отменить.
- Когда все четыре ячейки ровно на нуле — поздравление с аплодисментами и конфетти.
- В полночь по времени Уфы / Перми / Екатеринбурга (UTC+5) день сбрасывается.
- Хранится история за последние 7 дней. Внутри claude.ai данные сохраняются в аккаунте (capability `db`) и синхронизируются между устройствами; при открытии файла напрямую — только в `localStorage` браузера.
